## 4. 判断材料の要約

- **Keep は取れない**: G-1 / G-2 は b51 が加えた振る舞い（監査文言の順序・構造化面の失敗経路）で、設計に無い。G-3 は設計本文（W2.1 / BR3.4）が現行の排他方式と食い違う（設計内でも §7 表とは矛盾）。
- **Redo は要らない**: W1〜W8・§5 の U7 表・BR 17 本の骨格は現行コードと一致（§2）。ずれは記述の追従と対応表の精密化で閉じる。
- **Modify の範囲**: entities（属性対応表・`state` / 排他の制約・anchor / verified 追加）、rules（BR2.1 / BR2.3 / BR3.4 の logic）、functional-spec（W2.1 / W6 / W7 / W8 表 / §4 / §5 / §7）、traceability は不変。契約側 1 件（RECOMPOSED の列挙順）は contract-design pending-revision へ折り戻す。

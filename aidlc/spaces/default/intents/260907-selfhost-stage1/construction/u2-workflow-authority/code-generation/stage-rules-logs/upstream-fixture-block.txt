読み取れること:
- `team.md` は見出しと出荷テンプレートの前書きとコメントだけなので束に載らない
  （本家 `isSubstantiveRuleText`）。org / project / phases の 3 件だけが載る。
- 束のダイジェストは `[{path,text},...]` の `JSON.stringify` に対する sha256 であり、
  `path` は `aidlc/spaces/<space>/memory/<subpath>` の POSIX 綴りである
  （`AIDLC_RULES_DIR` で読取先を差し替えても綴りは変わらない）。
- 非 ASCII は生のまま。`"` と `\` はエスケープ。タブは `\t`。
- ブロックは `\n\n<!-- ... BEGIN ... -->` で始まり `--> ` ではなく `-->` で終わる
  （末尾に改行を付けない）。

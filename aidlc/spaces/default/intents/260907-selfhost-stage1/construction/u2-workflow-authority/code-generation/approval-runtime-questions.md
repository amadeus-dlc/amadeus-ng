# 承認状態の共有範囲と保存先

## 実測した差分

本家2.7.1固定コミット `a277af218f0df7f325d3b8be7b6d90fce2c5bd40` の `dist/claude/.claude/tools/aidlc-lib.ts` は、承認用の照合情報・人間応答・受領を `aidlc/.aidlc-sessions/plan-approval/` へ置く。`sessionsDir`（2557–2558行）と `planApprovalRuntimeDir`（2688–2689行）にspaceやintentの区分はない。通常の指示発行に伴う `resetPlanApprovalRuntime`（2788–2795、5222–5227行）は、この共有範囲を失効させる。

現コードの `modules/core/command/domain/src/workspace/store_path.rs` は、`aidlc/spaces/<space>/intents/.aidlc-store.sqlite` をspaceごとの保存先としている。承認状態を各 `IntentExecution` だけに置くと、別の依頼やspaceでの指示発行による失効を表現できない。

## 提案する契約差分

- ワークスペース全体の承認状態を所有する `PlanApprovalRuntime` 集約を追加する。依頼ごとの進行状態と、全体で共有される承認状態の所有者を分ける。
- 共有範囲の保存先を `aidlc/.aidlc-runtime.sqlite` とする。既存と同じ `event-store-adapter-rs`、SQLite、RMUを使い、既存spaceのデータは移動しない。
- 共有集約のイベント、チェックポイント、クエリ用の `read_*` 表はこの共有ファイルへ置く。コマンドは集約のイベントを追記して `Result<(), E>` を返し、RMUが投影、Queryが対象IDで読む。
- `aidlc/.aidlc-sessions/plan-approval/` の本家互換ファイルは投影結果とする。失効はイベントで記録し、イベント履歴のあるSQLiteを削除して表現しない。
- 既存spaceの状態・監査への反映も、既存のイベント保存とRMUの経路を使う。複数更新の途中で失敗した場合の識別、再開、重複防止を契約テストで検証する。異なるストアが同じ監査ファイルを独立に上書きする構成にはしない。
- SQLite本体とWAL/SHM等をGit管理外にする。利用済みの共有ストアの欠落・不読・投影不整合は自己診断へ渡す。診断のための空ストア作成は行わない。

承認済みの[契約書](../../../inception/contract-design/contract-summary.md)は「別データベース…を導入する仕様ではない」と記し、[要求書](../../../inception/requirements-analysis/requirements.md)のNFR1は既存のイベントソーシング・投影方式を維持する。この提案は方式を維持した保存先の追加だが、追加ファイルは承認済みの配置に含まれていないため、利用者の「上流仕様と現行コードが食い違ったら裁定を求める」という指定に従い、この差分を確認する。

## Q1: 共有する承認状態をどこへ保存するか

A. 上記の共有集約とSQLiteファイルの追加を承認する（推奨）。既存のspace別保存を維持して、ワークスペース共有の失効を実装する。

B. 保存先の追加を承認せず、既存の保存構成への配置を再検討する。配置と共有範囲の新しい案を提示してから実装する。

[Answer]: A. 共有集約とSQLiteファイルの追加を承認する。

利用者の番号回答「1」を上記Aへ対応付けた。既存データを移動せず、同じイベント保存・RMU・Queryの方式を使う保存先追加を承認した。

利用者から「これまでのDDDの原則を逸脱しないならOK」と補足を受けた。ワークスペース全体の承認状態を管理する集約という意味であり、集約の境界とDBの配置は別の設計事項である。状態の所有、集約間のID参照、集約による判断とイベント生成、Repositoryでの保存、RMUでの投影、Queryによる読取りという既存原則を維持し、例外を設けない。

## 承認後に必要な検証

別intent・別spaceの通常指示発行による失効、停止フックの確認呼び出しでは失効しないこと、別セッション・古い回答・受領再利用の拒否、途中の保存/投影失敗と再開、状態・監査・承認ファイルの本家比較を実施する。保存先の承認を、これらの検証に成功した証拠として扱わない。

裁定を記録した時点では、共有ストアの作成・配線はまだ行っていない。上記の追加を実装し、検証を継続する。
